# data

This folder contains the data used in generating papla-GEM.

### biomass

Biomass composition data and curation, including bioreactor growth measurements used to fit the biomass equation.

### genomes

Genome, CDS and protein FASTA files for _Papiliotrema laurentii_ UFV-1, together with the protein sets of the template organisms (_Rhodotorula toruloides_, _Yarrowia lipolytica_) used for homology-based reconstruction.

### meneco

Files for running [MENECO](https://github.com/bioasp/meneco) gap-filling analysis; see the folder's own `README.md` for instructions.

### reconstruction

Manual curation and reaction/template tables used while reconstructing the model, e.g. lipid and SLIME reaction templates, and gene-reaction rule updates.

### results

Output files from model analyses, e.g. growth predictions, carbon source usage, and overexpression target screens.

### templateModels

Template GEMs used as a starting point for the reconstruction: rhto-GEM (_R. toruloides_), iYali (_Y. lipolytica_), and a _S. cerevisiae_ model.
